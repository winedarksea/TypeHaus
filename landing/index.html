What it does

One source of truth, from sketch to permit set.

Plan source you can read

Nodes, walls, openings, rooms and assemblies are plain keyword-arg declarations — diffable, mergeable, and safe to hand-edit or vibe-code.

Runs fully offline

The engine compiles to WebAssembly and edits plan source in a pure-Python writeback path — no server round-trip, works on a plane.

Clean exports

Deterministic IFC with stable GlobalIds, plus DXF/PDF sheets — round-trip an architect's IFC changes back into source.

Building science built in

Assemblies carry control layers and R-values; checks flag code, structural, and envelope issues as you edit.

Stable identity

Every element keeps an immutable uid, so retagging or moving between storeys never breaks its downstream references.

Look, don't guess

Render plan and 3D snapshots after every edit — spatial judgment joins the text findings.

Two ways in

Start in the browser; drop to the CLI when you want full IFC export and macros.

1
Open the app. type-house.com/app loads the Catlin reference house by default — pan, edit a wall, undo, all offline.
2
Install locally. curl -LsSf https://type-house.com/install.sh | sh for the full engine.
3
Serve your own house. haus new my-house then haus serve — same editor, plus IFC export and parametric macros.
